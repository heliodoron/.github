# Security policy

## Scope

The repositories in this organization are demonstration systems that run on
synthetic data. They are not production services. Reports about the code,
its dependencies and its workflows are welcome.

## Supported versions

Only the current `main` branch of each repository is supported.

## Reporting a vulnerability

Do not open a public issue, discussion or pull request for a security
problem.

1. Use the "Report a vulnerability" button on the Security tab of the
   affected repository. The report stays private.
2. If that is not possible, write to hello@heliodoron.com.

Please include the affected repository and file paths, the steps to
reproduce, and the impact you expect.

## What to expect

Reports are handled on a best-effort basis. There is no bounty and no
guaranteed response time. A confirmed problem is fixed on `main`, and the
reporter is credited in the fix unless they ask not to be.
